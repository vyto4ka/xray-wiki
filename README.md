# xray-wiki

Двуязычный статический справочник по **Xray-core** (`RU` / `EN`) с базой сетевых понятий, точечными ссылками на китайский первоисточник (`https://xtls.github.io/` и связанные спецификации `XTLS/Xray-core`) и статическим полнотекстовым поиском **Pagefind**.

## Возможности

- **Две локали (`RU` / `EN`)** с сохранением открытой статьи и якоря (`#anchor`) при переключении языка и мягким фоллбэком для ещё не переведённых страниц.
- **Сквозной сетевой глоссарий (`:term[...]`)**: всплывающие подсказки и прямые ссылки на подробные объяснения TCP/UDP/QUIC, TLS/SNI/ALPN/ECH, DNS/FakeDNS, DPI, uTLS, NAT и Linux `splice()`.
- **Точечная сверка с первоисточником (`:orig[...]`)**: аккуратные боковые ссылки на конкретный раздел или фрагмент текста (`#:~:text=...`) в официальной документации и спецификациях GitHub, плюс режим сверки `原` в шапке.
- **Полнотекстовый поиск Pagefind (`Ctrl+K` / `/`)** по русским, английским и оригинальным китайским терминам без выделенного бэкенда.
